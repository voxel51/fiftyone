# Shrinking allow-list for the keyboard-shortcuts consolidation.
#
# Every file here still attaches its own keydown/keyup listener to document,
# window, or an element. The keymap design doc's §4.1 requires a single
# capture-phase listener owned by @fiftyone/keymap, and the reason is concrete:
# the old bus listens on the bubble phase, so its stopPropagation() cannot stop
# these siblings, and three separate authors independently worked around that
# with {capture: true} and stopImmediatePropagation().
#
# The eslint rule that reads this file warns on any new listener outside the
# list. Remove entries as their owners migrate onto useKeyBinding /
# useDismissable; do not add to it.
#
